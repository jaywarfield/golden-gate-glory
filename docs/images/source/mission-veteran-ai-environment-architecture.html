🚂 Railway — Live Bridge Server
Dockerfile · push to main → auto-redeploy
start.sh at container startup:
1. Reads RAILWAY_PUBLIC_DOMAIN (auto-set by Railway)
2. Derives API_BASE=https://<domain>
3. Injects window.API_BASE into web/index.html
4. Flips USE_MOCK=false
5. Starts uvicorn src.server:app --port $PORT
Env vars set in Railway dashboard:
WATSONX_API_KEY · WATSONX_PROJECT_ID · WATSONX_URL
ALLOWED_ORIGINS · API_BASE (optional override)
USAJOBS_API_KEY · USAJOBS_USER_AGENT
POST /api/translate GET / → index.html GET /health
