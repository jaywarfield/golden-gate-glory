Railway  Docker · live AI
Builds & runs the Dockerfile on push to main.
Injects RAILWAY_PUBLIC_DOMAIN → start.sh writes window.API_BASE into index.html and flips USE_MOCK = false before starting uvicorn.
Dynamic port via $PORT; env vars WATSONX_API_KEY, WATSONX_PROJECT_ID, WATSONX_URL set in Railway dashboard.
