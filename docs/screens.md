# **Mission Veteran AI** *by G3*

#### Screen Descriptions

##### Screen 1: Welcome and Consent
```
Review Welcome.

Consent choice: Select I Understand and agree

Draft storage: Select Entire session  

Select Continue to Intake
```

##### Screen 2: Guided Career Intake
```
Select branch: Air Force, Army, Coast Guard, Marine Corps, etc

Specialty code: (Choose specialty code for selected branch) 

Service resume: (Drag & drop resume or upload local file)

Target career path: (Preset from speciality code or enter your own)

Target career role: (Select from predefined list or enter your own)

Select Translate Accomplishments

Review translated, make changes as needed, select translate again.

Select Continue to Job Description

```

##### Screen 3: Job Description Analysis
```
Job description text: (Drag & drop description or upload local file)

Select Analyze Job Description

Review job analysis, make changes as needed, select analyze again.

Select Continue to Skill Mapping
```

##### Screen 4: Civilian Skill Profile & Gap Analysis
```
Select Map Skills & Analyze Gaps

Review career path coverage and civilian skill inventory

Select Continue to Resume Draft
```

##### Screen 5: Resume Builder
```
Select Build Tagged Resume Draft

Review resume draft:
- EVIDENCED is already validated.
- INFERRED should already have.
Note: Review where inferred from and select Add or Delete.
- MISSING but required in job description.
Note: Review whether already have and select Add or Delete. 

Select Continue to Interview Prep
```

##### Screen 6: Interview Preparation
```
Select Generate Interview Prep

Interview prep is displayed as flashcards.
Questions are initially displayed.
To view response select “Tap to see STAR response”.
To return to question select “Tap to return to question”.
```

##### Screen 7: Export Gate & Final Package
```
Select Evaluate Gate

Review gate details

Select Continue to Export Gate

Save Resume draft
```
