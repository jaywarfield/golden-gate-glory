# **Mission Veteran AI** *by G3*

**Screen 1: Welcome and Consent**
```
Review Welcome.

Consent choice: Select I Understand and agree

Draft storage: Select Entire session  

Select Continue to Intake
```

**Screen 2: Guided Career Intake**
```
Select branch: Air Force, Army, Coast Guard, Marine Corps, Navy, Space Force

Specialty code: (Choose specialty affiliated with selected branch) 

Service resume: (Drag & drop military resume or select a local file to upload)

Target career path: (Choose career path affiliated with selected specialty)

Target career role: (Choose career role affiliated with selected career path)

Select Translate Accomplishments

Review translated accomplishments, make changes, select translate again.

Select Continue to Job Description

```

**Screen 3: Job Description Analysis**
```
Job description text: (Currently cut-and-paste but eventually drag & drop job description or select a local file to upload)

Select Analyze Job Description

Review job analysis, make changes, select analyze again.

Select Continue to Skill Mapping
```

**Screen 4: Civilian Skill Profile & Gap Analysis**
``
Select Map Skills & Analyze Gaps

Review career path coverage and civilian skill inventory

Select Continue to Resume Draft
```

**Screen 5: Resume Builder**
```
Select Build Tagged Resume Draft

Review resume draft:
- EVIDENCED is good.
- INFERRED from the veteran job type that should already have this experience even if not mentioned upfront by the veteran, and if acceptable click Confirm. 
- MISSING from the veteran’s experience but required in the job description, and if acceptable click Remove. 

Select Continue to Interview Prep
```

**Screen 6: Interview Preparation**
```
Select Generate Interview Prep

Review interview prep and go back to fix any blocks (inferred and missing must be fixed).
```

**Screen 7: Export Gate & Final Package**
```
Select Evaluate Gate

Review gate details

Select Continue to Export Gate

Save Resume draft
```
